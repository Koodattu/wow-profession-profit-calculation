# Item expansion reference

Derived from [erorus/shatari-data](https://github.com/erorus/shatari-data),
Copyright 2026 Gerard Dombroski, licensed under the Apache License, Version 2.0.
A copy is included in `item-expansions.LICENSE`.

Copper modified the data by merging the historical item-to-era mapping with the
era fields in Undermine Exchange's generated public mainline item catalogs and
removing other fields. Source URLs, source commit, retrieval time, SHA-256 source
checksums and a normalized content checksum are embedded in the compressed file.
World of Warcraft game data originates with Blizzard Entertainment.

See `docs/item-expansions.md` for semantics, limitations and the update procedure.
